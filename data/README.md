# data/

Sem patří vstupní data pro 3. díl seriálu — strojové klasifikace Gravity Spy.

**Zdroj:** Zenodo DOI [10.5281/zenodo.5649212](https://doi.org/10.5281/zenodo.5649212), licence CC BY 4.0.

Pro první verzi stačí `H1_O1.csv` (~16 MB, 15 305 řádků, 43 sloupců):

```
curl -L -o H1_O1.csv https://zenodo.org/api/records/5649212/files/H1_O1.csv/content
```

Soubory jsou v `.gitignore` — nestahují se do repa, každý si je vytáhne sám.
